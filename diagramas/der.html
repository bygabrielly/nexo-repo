services

  • id (PK)
  • user_id (FK → users.id)
  • title
  • description
  • category
  • price
  • keywords
  • created_at

messages

  • id (PK)
  • service_id (FK → services.id)
  • sender_id (FK → users.id)
  • receiver_id (FK → users.id)
  • content
  • created_at
Um usuário (freelancer) publica vários serviços e vários itens de portfólio (1:N em ambos os casos). Um serviço pode receber várias mensagens (1:N). Um usuário pode enviar e receber várias mensagens, papéis representados pelas chaves estrangeiras sender_id e receiver_id, ambas referenciando users.id (relação 1:N tracejada).
